# SASIBIOS（PC-9801 の SASI 固定ディスク BIOS、クリーンルームの実装）

PC-9801 のノーマルモード用の SASI 固定ディスク BIOS を、機能の仕様書だけから書き起こしたもの。

- `docs/sasibios_spec.md`: 機能の仕様書。NEC の SASI BIOS とコントローラの動きを調べた者（調査側）が、自分の言葉で書いた。
  NEC の ROM の中の番地、命令の並び、逆アセンブルの抜き書きは入れていない（仕様書の 0 節）。仕様書が引く参考資料は、末尾の「参考資料」の節にまとめた。
- `sasibios/sasi.asm`: 実装。調査側とは別のセッション（実装側）が、仕様書と公開の資料だけを見て書いた。
  NEC の ROM、その逆アセンブル、ほかの人のディスク BIOS のソースは見ていない。
- `QUESTIONS.md`: 実装側が仕様書に出した疑問と、その答え（仕様書の版）。
- `sasibios/impl_tests/`: 実装側が初めに仕様書だけから書いた模型と試験（記録。いまの実装では通らない試験がある）。

ビルド: `python3 sasibios/mkrom.py`（nasm が要る。4 KB の全バイトの和を 00h に合わせた `sasibios/sasi.rom` を書く）。

ビルド済みの ROM: `sasibios/sasi.rom`（実装側が `sasi.asm` と一緒にコミットしたもの。4 KB）。
調査側も同じソースを別にビルドし、SHA-256 が合うことを確かめて、いちばん上の `SHA256SUMS` に書いた。
自分でビルドしても同じバイト列になるはず（nasm の版が違うと変わることがある。使った版は下の「ビルドの記録」）。

- `bios/test/`: 調査側が用意した試験と模型（本体の BIOS、SASI のターゲット、8237、8259 の模型）。仕様書の 4〜6 節の約束を真似たもので、NEC のコードは含まない。
  `python3 bios/test/sasi/test_sasi.py`、`python3 bios/test/sasi/test_detail.py` で、`sasibios/sasi.asm` が仕様書に合っているかを確かめる（nasm と unicorn が要る）。

試験と模型（`bios/test/`）と仕様書は調査側が、実装（`sasibios/`）は実装側が書いた。

**NEC の SASI BIOS との類似性の調査**（2026-11-05、調査側）: ビルドした `sasi.rom` を、NEC の SASI BIOS の 4 つの版と比べた。
バイトの並びと、即値と番地を消した命令の並びで比べ、空きの詰め物（同じバイトの連続）は数えていない。

| 組 | バイトの最長の一致 | 共通の 16 バイトの並び | 命令の最長の一致 | 6 命令の並びの重なり（Jaccard） |
|---|---|---|---|---|
| `sasi.rom` と NEC の 4 版 | 22〜24 バイト（パラメータ表の中） | 52〜64 | 10〜12 命令 | 0.010〜0.014 |
| パラメータ表を除いた `sasi.rom` と NEC の 4 版 | 16 バイト | 1 | 10〜12 命令（ROM の頭の形） | 0.004 |
| NEC の版どうし | 55〜275 バイト | 337〜1,780 | 33〜327 命令 | 0.088〜0.392 |
| 関係のないコードどうし（目安） | 4〜7 バイト | 0 | 3〜5 命令 | 0.000 |

NEC の版どうしの行は、同じ系統のコード（前の版を引き継いで改めたもの）がこの比べ方でどう見えるかの目安。関係のないコードどうしの行は、引き継ぎのないコードの目安。
- パラメータ表を除いた行は、`sasi.rom` のパラメータ表（30 バイト × 7 個）を空きに置き換えて比べたもの。コードどうしの似かたを示す。
- 命令の最長の一致（10〜12 命令）は、どちらの行でも ROM の頭の形（0000h〜0008h の RETF、NOP、NOP の 3 回と、55h AAh、ID のバイト。仕様書の 1.1 と 4.1）を命令として読んだもの。11 バイトなので、バイトの比べ（16 バイト以上）には入らない。
- パラメータ表の中のバイトの一致が 22〜24 バイトで切れるのは、表の持ち方が少し違うため。仕様書の 3.2 が決めている欄（+00h〜+14h、+18h、+1Ch）は同じ値で、仕様書が「そのほか: 0（使わない）」とする欄（+15h〜+17h、+1Ah、+1Bh）を、`sasi.rom` は 0 にし、NEC の版は値を入れている。

`sasi.rom` の中で、NEC の 4 版のどれかと 16 バイト以上続けて一致した所は、次の 2 つだけ（16 バイトより短い一致は数えていない）。

| `sasi.rom` の中で 16 バイト以上一致した所 | 大きさ | 中身 |
|---|---|---|
| パラメータ表（30 バイト × 7 個） | 207 バイト | 値は仕様書の 3.2 が決めている事実の値 |
| INT 1Bh の出口の処理 | 16 バイト | 仕様書の 6.1 の出口の決まり（結果の AH を [BP+1] に、AH ≥ 20h なら [BP+16h] の CF を立てる）をそのまま命令にしたもの |
| 合わせて | 223 バイト | 使っている 3,769 バイトの約 6 % |

**ビルドの記録**: 調査側は NASM version 2.16.01 でビルドし直し、`sasibios/sasi.rom` と同じバイト列であることを確かめた（4096 バイト、SHA-256 608b96d5b3c57d749f2cf872de5b7c3661dfeb48241d1a9086b377891cff1f71）。
